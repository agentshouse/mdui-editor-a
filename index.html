    About dokieli

    Original dokieli ProseMirror editor, author toolbar, semantic article layout, tables, images, local notes, metadata and document templates. Explicit Save uses House guarded drafts.

    External lookup, notifications, social publication, sign-in, remote media and live cursor collaboration are unavailable. HTML export excludes separately bundled styles/fonts; printing and the donor full-screen presentation runtime are not enabled. Seed documentation describes upstream capabilities.
